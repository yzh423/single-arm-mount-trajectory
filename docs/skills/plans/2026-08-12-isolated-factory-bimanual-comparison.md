# Isolated Factory Bimanual Comparison Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an isolated dual-arm MuJoCo experiment package comparing strict bimanual multibranch IK, existing DualArmEasyIKPVT, and conditionally initialized DualArmMPCPVT on two complete factory CSV trajectories for xArm6, Franka Panda, I2RT YAM, and UR5.

**Architecture:** All new production code lives in `factory_bimanual/`, all new tests live in `tests/factory_bimanual/`, and all artifacts live in `reports/factory_bimanual/`. Existing single-arm modules may be imported through narrow read-only adapter interfaces, but no existing single-arm source, configuration, cache, report, or test file may be modified.

**Tech Stack:** Python 3.11, NumPy, pandas, MuJoCo, existing `DualArmEasyIKPVT`, existing `DualArmMPCPVT`, pytest, ffmpeg/OpenCV.

## Global Constraints

- Existing single-arm files are read-only and must remain byte-identical.
- Create no output under `reports/single_arm/` or `videos/single_arm/`.
- Use complete CSV timelines without cropping, scaling, per-hand offsets, or robot-specific task registration.
- Only same-model bimanual experiments are included.
- Panda retains seven active joints per arm; locked-J3 Panda is excluded.
- Each robot uses one upright, symmetric, fixed base spacing for both tasks.
- Reuse existing EasyIK and MPC equations/policies through an isolated native-DOF port; external controller and single-arm files remain read-only.
- Strict thresholds remain 1 mm and 1.5 degrees.
- A/EasyIK first-frame wrapped joint difference below 5 degrees on both arms collapses MPC-A/MPC-B to one canonical MPC run.
- This workspace is not a Git repository; create a manifest of protected single-arm file hashes before implementation and verify it after every task.
