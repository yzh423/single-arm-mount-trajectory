# Piper X Seal Bag 三种安装方向对比实验设计

## 目标

在同一 Seal Bag 双臂轨迹、同一 XY 搜索区域和相同求解预算下，比较两台官方 Piper X 在桌面竖装、墙面横装和倒挂三种安装方向中的能力上限。每种方向独立优化 mount，但搜索边界、采样密度、筛选阶段与评价口径保持一致。

## 固定条件

- 输入轨迹：`data/factory/8-11/Seal_Bag/handheld_20260811_161504.csv`，完整 2439 个源帧。
- 机器人：项目内官方原生尺度 Piper X；左右臂型号、碰撞模型和求解器配置相同。
- 每个候选搜索左右臂 `x/y`、共享世界坐标 `z` 和各自 `yaw`；左右臂的世界坐标 `z` 必须完全相同。
- 三组使用相同 XY 边界、共享 z 边界、yaw 网格、IK 迭代次数、候选数、beam 宽度及 refinement 预算。
- 不修改原有单臂实验代码或结果。

## 安装方向

1. 桌面竖装：两底座轴均朝世界 `+Z`，安装面为水平桌面。
2. 墙面横装：两底座轴均为水平，并分别朝向 Seal Bag 轨迹中心；安装面为对应的竖直墙面。
3. 倒挂：两底座轴均朝世界 `-Z`，安装面位于轨迹上方。

安装方向是离散实验变量，不搜索连续 roll/pitch。`yaw` 始终定义为绕各自底座法向旋转。

## 搜索流程

1. 使用同一确定性扩展网格生成三组候选。
2. 对代表性时间点做左右臂联合 IK、真实 MuJoCo 状态碰撞和帧间扫掠碰撞检查。
3. 保留固定数量的安全候选，进行联合局部 `x/y/z/yaw` refinement。
4. 对每种安装方向的 finalist 求解完整 2439 帧。
5. 只有完成全时间轴审计且无真实碰撞的候选可以成为该方向的最终 mount。

二维投影交叉、结构投影重叠和夹爪投影重叠只作为诊断与同等跟踪质量下的次级排序项，不等同于三维碰撞，也不会单独淘汰候选。

## 排序准则

安全门通过后，按以下字典序选择：

1. 更高的双臂同步连续覆盖率；
2. 更短的最长连续失败区间；
3. 更少的受限恢复或 relaxed-tier 帧；
4. 更小的位置和姿态误差；
5. 更大的最小关节裕量与奇异性裕量；
6. 更低的关节速度峰值和轨迹总变差；
7. 投影交叉程度更低；
8. 求解耗时更短。

## 指标与产物

每种安装方向保存：

- 最终左右 mount 的 `x/y/z/yaw` 和固定安装旋转；
- 左臂、右臂、同步与连续覆盖率；
- 失败帧、最长连续失败、失败时间窗及失败原因；
- TCP 位置误差和姿态误差的 mean/P50/P95/max；
- 每关节轨迹、速度、最小关节裕量和奇异性裕量；
- 状态碰撞、扫掠碰撞、桌面/墙面/底座/双臂碰撞分类；
- 搜索候选数、各阶段淘汰数、运行时间及完整审计指纹；
- JSON、NPZ、CSV 汇总、图表和中文 PDF 报告。

## 视频

- 三种安装方向各输出一段 MP4。
- 使用相同正面相机构图、分辨率、帧率和原始源时间轴。
- 视频同时显示目标轨迹、实际 TCP、当前时间、跟踪状态和碰撞/恢复诊断。
- 视频必须经过实际解码校验；求解失败或渲染失败独立记录，不用静态帧伪装成功。

## 报告结构

报告参考 `xarm6_single_trajectory_optimization_report.pdf` 的图形化风格，包括：核心指标总览、三种安装视觉关键帧、三维目标/实际轨迹、误差时间序列、失败窗口、关节裕量与速度、完整指标表、客观结论和限制。三组结果分别与桌面竖装基线计算绝对差值和相对变化。

## 完成标准

- 三组执行完全相同的搜索协议和完整轨迹审计；
- 所有正式入选 mount 均无 MuJoCo 状态或扫掠碰撞；
- 指标能从保存的逐帧数组重新计算；
- 三段视频可解码且时间长度与源轨迹一致；
- PDF 中的数值与 JSON/NPZ/CSV 一致，并完成逐页渲染检查。
