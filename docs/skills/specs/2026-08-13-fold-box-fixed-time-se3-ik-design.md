# Fold Box 固定总时长 SE(3) 与 IK 连续性优化设计

## 目标

在不增加 `handheld_20260811_160754.csv` 总时长、不放宽 1 mm / 1.5° TCP
容差、不超过 3.14 rad/s 关节速度且不引入碰撞的前提下，减少 Fold Box
双臂轨迹中频繁的 IK 停顿、恢复拖尾和视觉抽动。

当前正式 mount 保持：左 `(-0.3757733963, 0.2812066419)`、右
`(-0.2917091328, -0.1741818985)`、yaw 分别为 315°/45°、共同 Z=0.87 m。

## 已确认的根因边界

- 每个源帧两臂都有 2–8 个满足严格位置与四元数姿态容差的 6D IK 解；不存在单帧
  pose unreachable。
- 左臂 97 条、右臂 112 条相邻候选边在所有分支组合下都超过源时间允许的关节
  速度；碰撞单独造成的不可行边为 0。
- 这些不可行边主要对应源四元数的“保持一帧、下一帧集中跳变”：左 97 条中 95 条、
  右 112 条中 102 条超过 180°/s 姿态速度。
- 当前 bounded recovery 又产生左 69 帧、右 30 帧误差传播。
- 增加 seeds、候选上限和 beam 不改善代表性失败窗口。

## 方案选择

采用“局部去隔帧重建 + 速度状态感知 IK”的组合方案。

不采用全局低通滤波，因为它会改变正常运动段与关键操作姿态；不采用全局重定时，因为用户
要求总时间不增加；不继续堆叠随机 IK seeds，因为反事实已经证实无收益。

## 轨迹重建

新增一个独立、可测试的四元数轨迹重建函数，输入为严格递增时间戳和 WXYZ 单位四元数。

1. 统一相邻四元数符号，使用最短测地线。
2. 检测“上一条姿态边近似静止、下一条边显著运动”的中间样本。
3. 仅将该中间样本按真实时间比例放置到前后姿态之间，使用 SLERP。
4. 首帧、末帧、时间戳、帧数和总时长必须逐项保持。
5. 未被检测为隔帧保持的样本保持原值；位置轨迹本轮不修改。
6. 输出每帧是否被重建及改变量，写入轨迹 NPZ 和汇总报告。

检测阈值必须显式配置并通过实际数据审计固定，不能根据目标覆盖率反向调参。末尾 68 mm
位置异常不通过本函数处理，继续作为源数据异常显示。

## IK 连续性

`select_rolling_branch` 增加可选 `initial_velocity_rad_s`，默认仍为零以保持其他调用者兼容。
Fold Box 滚动规划在每帧传入最近一个实际关节速度；窗口第一条边的加速度代价由
`(qdot - initial_velocity) / dt` 计算，而不是总是假设从静止开始。

bounded recovery 继续严格逐关节限速，并继续执行 swept-collision 检查。本轮不允许瞬时重置、
跨分支 teleport 或放宽 TCP 容差。若局部去隔帧后仍存在不可行边，必须保留真实失败标记。

## 诊断语义

视频与报告将失败拆分为：

- `SOURCE TIMING INFEASIBLE`：当前候选层与上一候选层不存在任何速度/碰撞可行边；
- `RECOVERY PROPAGATION`：候选图已重新可连接，但实际限速状态仍未回到 TCP 容差；
- `POSE UNREACHABLE`：当前帧没有严格 6D IK 候选；
- `COLLISION BLOCKED`：存在速度可行边但全部被碰撞过滤。

只有实际 TCP 超出严格容差或发生碰撞时显示 `CANNOT FOLLOW`。已重新进入容差但 recovery
模式尚未清除的帧不得计入 failure reason。

## 验证与验收

单元测试先失败再实现，覆盖：

- SLERP 最短路径、单位范数与非均匀时间比例；
- 仅修复 hold-then-jump 样本；
- 首尾、帧数、时间戳和总时长不变；
- 正常恒速旋转不被修改；
- 滚动分支评分使用传入的初速度；
- 默认初速度保持既有行为；
- 四类诊断互斥且严格成功帧原因必须为 `ok`。

完整 Fold Box 验收：

- 执行时长精确保持 23.509543792 s；
- 位置/姿态容差保持 1 mm / 1.5°；
- 最大关节速度不超过 3.14 rad/s；
- 状态与 swept-edge 碰撞均为 0；
- 首尾双臂目标姿态不变；
- 同步覆盖率和不能跟随帧数不得劣于当前 86.8635% / 258 帧；
- 报告去隔帧前后姿态速度分布、源时序不可行边数和 recovery 传播帧数；
- 重新渲染 1280×720、60 FPS 正面视角完整视频，并保留当前版本用于逐帧对照。

## 实施边界

本轮不修改 CSV 原文件，不延长任务时间，不改变 mount，不引入倾斜，不调整机器人模型关节
限位，也不通过放宽容差或提高速度上限制造成功率。
