# Fold Box 固定总时长局部时间重分配设计

日期：2026-08-13

## 目标

在不改变 Fold Box 双臂 TCP 位置、四元数目标、轨迹首尾状态和总时长
`23.509543792 s` 的前提下，通过全局 IK 分支选择与中间时间戳重分配，减少
`SOURCE TIMING INFEASIBLE` 和随后产生的 `RECOVERY PROPAGATION`。

## 非目标

- 不提高 xArm6 的 `3.14 rad/s` 关节速度上限。
- 不增加轨迹总时长。
- 不改变 mount、桌面高度、双臂安装高度或姿态注册。
- 不对 TCP 位置或四元数做平滑、删帧或修改。
- 本阶段不加入加速度或 jerk 硬约束，保持与 Seal Bag v5 相同的控制假设。

## 方案

### 1. 全局候选路径

沿用当前每帧 MuJoCo 6D IK 候选和碰撞过滤。对每条相邻候选边计算逐关节
最短所需时间：

```
required_dt(i, a, b) = max_j(abs(delta_q_j) / velocity_limit_j)
```

有限关节使用普通差值；只有显式 continuous hinge 使用最短周期差值。碰撞边不进入
候选图。动态规划目标按以下优先级排序：

1. 最小化整条路径所需时间总和；
2. 最大化关节限位裕量；
3. 最大化 Jacobian 奇异裕量；
4. 最小化 IK 位姿残差和关节运动量。

该规划不在中途执行 bounded recovery。空候选层或所有候选均碰撞时仍保留明确失败，
不能通过跨帧 teleport 连接。

### 2. 固定总时长分配

对选定路径得到每条边的 `required_dt`。设源总时长为 `T`：

- 若 `sum(required_dt) > T`，该路径在当前速度限制下有严格的全局时间不足证据；
- 若 `sum(required_dt) <= T`，先为每条边分配所需时间，再将剩余时间按源间隔权重分配；
- 每条边保留正的最小间隔，首帧时间为 0，末帧时间严格等于 `T`；
- 左右臂必须共享同一时间轴，双臂每条边采用两臂所需时间的最大值。

共享边时间定义为：

```
dual_required_dt[i] = max(left_required_dt[i], right_required_dt[i], minimum_dt)
```

剩余时间优先按原始 `source_dt` 比例分配，从而尽可能保留原始节奏。时间轴严格递增，
不改变帧顺序或帧数。

### 3. 诊断语义

- `GLOBAL DURATION INFEASIBLE`：所有选定边的最小时间之和超过源总时长；
- `POSE UNREACHABLE`：该帧没有严格 6D IK 候选；
- `COLLISION BLOCKED`：该帧或候选边只能通过碰撞路径连接；
- `SOURCE TIMING REDISTRIBUTED`：相对于 CSV 原始时间戳发生了时间借用，但轨迹可执行；
- 只有在重分配后的共享时间轴上仍超过速度上限，才保留 `TIMING INFEASIBLE`。

正常的时间重分配不应显示为不能跟随。

## 数据和产物

trajectory NPZ 新增：

- `redistributed_time_s`
- `source_dt_s`
- `redistributed_dt_s`
- `left_required_dt_s`
- `right_required_dt_s`
- `dual_required_dt_s`
- `time_borrowed_s`
- `time_redistributed`

summary JSON 新增：

- 最小所需总时长；
- 可用时间余量；
- 被延长和被压缩的边数；
- 最大借入/借出时间；
- 重分配后的速度峰值和违规数；
- 全局路径是否有严格固定总时长可行证书。

视频使用重分配后的时间轴播放，但总时长和帧数保持不变。轨迹目标仍使用原始帧数据。

## 错误处理

- 输入时间戳非严格递增、速度上限无效或候选图断开时立即报告具体错误；
- 总最小时间超出源总时长时不偷偷延长视频；保留安全路径并显示全局不足量；
- 碰撞检查同时覆盖状态和相邻插值边；
- 数值舍入后强制末时间等于源总时长，并重新验证所有间隔为正。

## 测试

### 单元测试

1. 高速边从低速边借时间，总时长严格不变；
2. 左右臂使用共享边时间的最大值；
3. 重分配后每关节速度不超过上限；
4. 总最小时间超过预算时返回不可行证书；
5. 时间轴严格递增，末时间精确保持；
6. 有限关节不使用周期 wrap；
7. 全局路径选择避开后期高速死路和碰撞边。

### Fold Box 验收

- 总时长精确为 `23.509543792 s`；
- 视频仍为 1280×720、60 fps、完整解码；
- 碰撞帧为 0；
- 关节速度不超过 `3.14 rad/s`；
- `SOURCE TIMING INFEASIBLE` 数量显著低于当前 L=30、R=57；
- `RECOVERY PROPAGATION` 显著低于当前 L=67、R=31；
- 不降低当前任务专属 mount 的几何安全性；
- 报告原时间轴与重分配时间轴的完整对照。

## 风险与限制

- 中间帧不再对应 CSV 原始绝对时间，只保留顺序、双臂同步和总时长；
- 局部节奏会改变，必须在视频和产物中明确记录；
- 仅约束速度不能证明真实硬件的加速度、jerk 或力矩可执行性；这与用户指定的
  Seal Bag v5 方案保持一致，应在结果中明确说明。
