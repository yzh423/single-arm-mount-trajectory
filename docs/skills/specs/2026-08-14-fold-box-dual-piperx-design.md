# Fold Box 双 PiperX 设计

日期：2026-08-14

## 目标

使用两个原生 PiperX 模型完成 Fold Box 双手 SE(3) 轨迹跟随。为 PiperX 独立搜索两个直立 mount；两底座保持同一世界 Z，高度不超过 0.87 m。输出正面 1280×720、60 FPS 完整视频及可审计轨迹。

## 方案

采用“扩展通用 robot contract + PiperX 专属 mount 搜索 + 通用 Fold Box 求解器”。不复制 xArm6 渲染器，也不套用 xArm6 mount。

未采用的方案：

1. 直接使用 xArm6 mount：速度快，但 PiperX 的臂长、关节限位和 TCP 不同，结果不可靠。
2. 只使用既有单臂严格搜索缓存：可提供初始 mount，但没有双臂交叉碰撞、共享时间轴和 Fold Box 全轨迹验证。

## PiperX 模型契约

- 每臂 6 个原生关节：`joint1` 至 `joint6`；
- 原生关节范围：`[-2.6179938,2.6179938]`、`[0,3.1415926]`、`[-2.9670597,0]`、`[-1.553343,1.553343]`、`[-1.553343,1.553343]`、`[-2.0943951,2.0943951]` rad；
- 原生速度上限：每关节 3.0 rad/s；
- base link：`base_link`；TCP 父链接：`gripper_base`；TCP 为父链接局部 +Z 方向 0.13 m；
- 场景保留原生夹爪几何，夹爪关节保持默认固定状态，不加入 6D arm IK；
- 安装只搜索 XY/yaw，roll/pitch=0；两臂共享 base Z，最大 0.87 m。

## 数据、mount 与 IK

1. 加载 `handheld_20260811_160754.csv`，沿用 Fold Box 的刚性平移注册。
2. 缺帧四元数先按既有规则重建，再做受限 SE(3) 平滑：位置逐帧改动不超过 3 mm，姿态不超过 1°。
3. mount 搜索先用包含端点、工作空间极值和困难区间的分层帧集筛选 XY/yaw，再对优胜候选执行完整 1964 帧验证。排序依次考虑同步严格覆盖率、碰撞、必要增时、奇异裕量和残差。
4. 每帧最多保留 8 个严格 6D IK 候选；路径搜索加入速度连续性代价，并限制单关节分支步长 35°、腕部三关节合成步长 45°。
5. 左右臂共享执行时间轴。速度使用每关节 3.0 rad/s；随后只增加必要区间以满足 60 rad/s² 中心差分加速度上限；jerk 硬约束关闭。
6. 状态和 swept-edge 均执行单臂自碰撞、台面碰撞和双臂交叉碰撞审计。

## 产物

输出到 `reports/factory_bimanual/fold_box_dual_piperx/`：

- 完整 MP4；
- trajectory NPZ；
- summary JSON；
- scene XML/manifest；
- mount 搜索候选及最终选择。

NPZ 分开保存原始、四元数重建后、平滑后与实际 TCP 数据，以及 qpos、源/执行时间、候选/分支、误差、速度、加速度、碰撞和失败原因。

## 验收

- 两底座世界 Z 相同且不高于 0.87 m；
- 位置 1 mm、姿态 1.5°严格覆盖率完整报告；目标是同步 100%，若无法达到必须显示失败窗口和理由；
- 速度不超过 3.0 rad/s，加速度不超过 60 rad/s²；
- 最终状态与 swept edge 碰撞为 0；
- 平滑改动不超过 3 mm/1°，且与缺帧重建分开报告；
- 正面 1280×720、60 FPS 视频全帧解码；
- 与最终 xArm6 Fold Box 结果比较覆盖率、执行时长、速度/加速度和剩余失败。

## 限制

结果是离线 MuJoCo 运动学、离散动态和碰撞验证，不等同于真实 PiperX 控制器的力矩、柔顺性或闭环认证。jerk 硬约束关闭，因此不声称 jerk 受控。
